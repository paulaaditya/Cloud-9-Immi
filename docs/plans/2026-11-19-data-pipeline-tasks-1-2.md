> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a fully-tested Python data pipeline that streams 160 GB of compressed VALORANT event data line-by-line and accumulates it into validated Pydantic v2 match-state models, with correct rollback handling for cancelled games.

**Architecture:** A thin config layer reads `STL_DATA_DIR` from the environment and resolves all dataset paths at import time. A streaming reader layer opens `.jsonl.zst` files with `zstandard` + `io.TextIOWrapper` and yields parsed JSON dicts one line at a time without loading whole files into memory. A Pydantic v2 model layer validates every event and accumulates per-round, per-game, and per-series state; it handles `series-!started-game` rollback events by marking invalidated game IDs and dropping their accumulated state.

**Tech Stack:** Python 3.11, zstandard 0.22+, Pydantic v2, pytest 8, pytest-cov

- [ ] **Step 1.7: Write minimal implementation — src/reader.py**

  ```python
  """
  reader.py — zero-copy streaming readers for the STL VALORANT dataset.

  Design constraints:
  - Never load a full .jsonl.zst file into memory; stream line-by-line.
  - Use `zstandard` (not compression.zstd which requires Python 3.14+).
  - Use io.TextIOWrapper so the caller gets a standard text iterator.
  - `load_ability_supplement` builds an in-memory index; supplement files are
    per-series and small relative to the full dataset.
  """

  import io
  import json
  import pathlib
  from typing import Iterator

  import zstandard


  def stream_series_events(path: pathlib.Path) -> Iterator[dict]:
      """
      Yield one parsed JSON dict per line from a .jsonl.zst series file.

      Parameters
      ----------
      path:
          Absolute or relative path to a .jsonl.zst file inside VAL_DIR.

      Yields
      ------
      dict
          The parsed JSON object for each non-empty line.

      Raises
      ------
      FileNotFoundError
          If `path` does not exist on disk.
      json.JSONDecodeError
          If a line is not valid JSON.
      """
      if not pathlib.Path(path).exists():
          raise FileNotFoundError(f"Series file not found: {path}")

      dctx = zstandard.ZstdDecompressor()
      with open(path, "rb") as fh:
          with dctx.stream_reader(fh) as compressed_stream:
              text_stream = io.TextIOWrapper(compressed_stream, encoding="utf-8")
              for raw_line in text_stream:
                  line = raw_line.rstrip("\n")
                  if line:
                      yield json.loads(line)


  def load_ability_supplement(path: pathlib.Path) -> dict[str, dict]:
      """
      Load an ability supplement .jsonl.zst file into a dict indexed by
      grid_event_id.

      The supplement file contains one JSON object per line, each with at
      minimum a `grid_event_id` field that maps to an event `id` in the
      corresponding series event stream.

      Parameters
      ----------
      path:
          Path to the .jsonl.zst file inside SUPPLEMENT_DIR.

      Returns
      -------
      dict[str, dict]
          Keys are `grid_event_id` strings; values are the full parsed row
          dicts. If `path` contains no rows the return value is an empty dict.

      Raises
      ------
      FileNotFoundError
          If `path` does not exist.
      KeyError
          If any row is missing the `grid_event_id` field.
      """
      if not pathlib.Path(path).exists():
          raise FileNotFoundError(f"Supplement file not found: {path}")

      index: dict[str, dict] = {}
      dctx = zstandard.ZstdDecompressor()
      with open(path, "rb") as fh:
          with dctx.stream_reader(fh) as compressed_stream:
              text_stream = io.TextIOWrapper(compressed_stream, encoding="utf-8")
              for raw_line in text_stream:
                  line = raw_line.rstrip("\n")
                  if not line:
                      continue
                  row = json.loads(line)
                  # Intentionally let KeyError propagate — a missing
                  # grid_event_id is a dataset integrity problem that must
                  # surface loudly rather than be silently dropped.
                  key = row["grid_event_id"]
                  index[key] = row
      return index
  ```

  ```python
  """
  models.py — Pydantic v2 match-state models for the C9 Oracle pipeline.

  Model hierarchy (bottom-up):
      Vector3D
          ^
      AbilityCast
          ^
      KillEvent   (ability_cast: AbilityCast | None)
          ^
      ParsedRound (kills: list[KillEvent])
          ^
      ParsedGame  (rounds: list[ParsedRound])
          ^
      ParsedSeries (games: list[ParsedGame])

  All models use strict field definitions. Extra fields are forbidden on
  Vector3D and AbilityCast (they come from supplement data we control) but
  allowed on KillEvent, ParsedRound, ParsedGame, and ParsedSeries because
  GRID event schemas evolve and unknown top-level fields should not break
  the pipeline.
  """

  from __future__ import annotations

  from pydantic import BaseModel, ConfigDict, Field, field_validator


  class Vector3D(BaseModel):
      """3D spatial coordinate or direction vector from the ability supplement."""

      model_config = ConfigDict(extra="forbid")

      x: float
      y: float
      z: float


  class AbilityCast(BaseModel):
      """
      One ability activation event, enriched with 3D spatial data from the
      val-ability-supplements dataset.

      The `event_id` matches the `grid_event_id` column in the supplement
      file and the `id` field in the series event stream.
      """

      model_config = ConfigDict(extra="forbid")

      event_id: str
      ability_name: str
      position: Vector3D
      aim_direction: Vector3D
      velocity: Vector3D


  class KillEvent(BaseModel):
      """
      A single kill extracted from a GRID `player-died` event.

      `round_number` is 1-indexed as reported in the GRID stream.
      `ability_cast` is None when the kill came from a firearm and the
      corresponding event id has no entry in the supplement index.
      """

      model_config = ConfigDict(extra="allow")

      event_id: str
      killer_id: str
      victim_id: str
      weapon: str
      round_number: int = Field(..., ge=1)
      ability_cast: AbilityCast | None = None

      @field_validator("round_number")
      @classmethod
      def round_must_be_positive(cls, v: int) -> int:
          if v < 1:
              raise ValueError(f"round_number must be >= 1, got {v}")
          return v


  class ParsedRound(BaseModel):
      """Accumulation of all kill events within one round of a game."""

      model_config = ConfigDict(extra="allow")

      round_number: int = Field(..., ge=1)
      kills: list[KillEvent]
      winner_team_id: str | None = None

      @field_validator("round_number")
      @classmethod
      def round_must_be_positive(cls, v: int) -> int:
          if v < 1:
              raise ValueError(f"round_number must be >= 1, got {v}")
          return v


  class ParsedGame(BaseModel):
      """All rounds within one map of a series."""

      model_config = ConfigDict(extra="allow")

      game_id: str
      map_id: str | None = None
      rounds: list[ParsedRound]


  class ParsedSeries(BaseModel):
      """
      The top-level unit of analysis: one best-of-N series between two teams.

      `games` only contains games that were NOT rolled back by a
      `series-!started-game` event. Rolled-back games are silently dropped
      during parsing (see src.parser for rollback logic).
      """

      model_config = ConfigDict(extra="allow")

      series_id: str
      games: list[ParsedGame]
  ```

  ```python
  """
  parser.py — stateful event stream accumulator for the C9 Oracle pipeline.

  Public API
  ----------
  parse_series(events_path, supplement_path) -> ParsedSeries

  State machine
  -------------
  The GRID event stream for one series arrives in roughly this order:

      series-started
      game-started            (may repeat for each map)
        round-started         (may repeat for each round)
          player-died         (zero or more per round)
        round-ended
      game-ended              OR series-!started-game  (rollback)
      series-ended

  Rollback handling
  -----------------
  When a `series-!started-game` event is seen for game_id G, all state
  accumulated for G is discarded and G is added to `_invalidated_game_ids`.
  Any subsequent events whose `gameId` matches an invalidated id are silently
  skipped. This handles corrupt or replayed streams without crashing.

  Supplement join
  ---------------
  `supplement_index` is a dict[str, dict] where the key is `grid_event_id`.
  For every `player-died` event we look up `event['id']` in the index. If
  found, we extract 3D caster position, aim direction, and velocity to build
  an `AbilityCast`. Supplement rows use the following field names:
      caster_x, caster_y, caster_z  — caster position
      aim_x,    aim_y,    aim_z     — aim direction unit vector
      vel_x,    vel_y,    vel_z     — velocity vector
      ability                       — human-readable ability name
  """

  from __future__ import annotations

  import pathlib
  from typing import Optional

  from src.models import (
      AbilityCast,
      KillEvent,
      ParsedGame,
      ParsedRound,
      ParsedSeries,
      Vector3D,
  )
  from src.reader import load_ability_supplement, stream_series_events


  def _build_ability_cast(
      event_id: str,
      supplement_index: dict[str, dict],
  ) -> AbilityCast | None:
      """
      Look up `event_id` in the supplement index and build an AbilityCast.

      Returns None if the event id is not in the index.
      """
      row = supplement_index.get(event_id)
      if row is None:
          return None
      return AbilityCast(
          event_id=event_id,
          ability_name=row["ability"],
          position=Vector3D(x=row["caster_x"], y=row["caster_y"], z=row["caster_z"]),
          aim_direction=Vector3D(x=row["aim_x"],    y=row["aim_y"],    z=row["aim_z"]),
          velocity=Vector3D(x=row["vel_x"],    y=row["vel_y"],    z=row["vel_z"]),
      )


  def parse_series(
      events_path: pathlib.Path,
      supplement_path: Optional[pathlib.Path],
  ) -> ParsedSeries:
      """
      Parse one complete VALORANT series from a .jsonl.zst event stream.

      Parameters
      ----------
      events_path:
          Path to the .jsonl.zst file inside VAL_DIR for this series.
      supplement_path:
          Path to the corresponding .jsonl.zst file inside SUPPLEMENT_DIR, or
          None if no supplement is available. When None, all KillEvent
          .ability_cast fields will be None.

      Returns
      -------
      ParsedSeries
          Fully validated Pydantic model tree. Games that were rolled back via
          `series-!started-game` are excluded from ParsedSeries.games.
      """
      # Load supplement index up-front; it fits in memory (~MB per series).
      supplement_index: dict[str, dict] = {}
      if supplement_path is not None:
          supplement_index = load_ability_supplement(supplement_path)

      # Accumulator state — mutated as we walk the event stream.
      series_id: str | None = None
      completed_games: list[ParsedGame] = []
      _invalidated_game_ids: set[str] = set()

      # Per-game transient state (reset on each game-started).
      current_game_id: str | None = None
      current_map_id: str | None = None
      completed_rounds: list[ParsedRound] = []

      # Per-round transient state (reset on each round-started).
      current_round_number: int | None = None
      current_round_kills: list[KillEvent] = []

      for event in stream_series_events(events_path):
          event_type = event.get("type", "")
          game_id = event.get("gameId")

          # ------------------------------------------------------------------
          # series-started: record series id
          # ------------------------------------------------------------------
          if event_type == "series-started":
              series_id = event.get("seriesId")

          # ------------------------------------------------------------------
          # game-started: begin accumulating a new game
          # ------------------------------------------------------------------
          elif event_type == "game-started":
              current_game_id    = game_id
              current_map_id     = event.get("mapId")
              completed_rounds   = []
              current_round_number = None
              current_round_kills  = []

          # ------------------------------------------------------------------
          # series-!started-game: rollback — discard the current game
          # ------------------------------------------------------------------
          elif event_type == "series-!started-game":
              if game_id is not None:
                  _invalidated_game_ids.add(game_id)
              # Drop any partially accumulated state for this game.
              current_game_id      = None
              current_map_id       = None
              completed_rounds     = []
              current_round_number = None
              current_round_kills  = []

          # ------------------------------------------------------------------
          # Skip all events that belong to an invalidated game.
          # ------------------------------------------------------------------
          elif game_id in _invalidated_game_ids:
              continue

          # ------------------------------------------------------------------
          # round-started: begin accumulating kills for this round
          # ------------------------------------------------------------------
          elif event_type == "round-started":
              current_round_number = event.get("roundNumber")
              current_round_kills  = []

          # ------------------------------------------------------------------
          # player-died: build a KillEvent, optionally enriched with ability data
          # ------------------------------------------------------------------
          elif event_type == "player-died":
              if current_round_number is None:
                  # Defensive: skip orphaned kill events.
                  continue
              ability_cast = _build_ability_cast(event["id"], supplement_index)
              kill = KillEvent(
                  event_id=event["id"],
                  killer_id=event.get("killerId", "unknown"),
                  victim_id=event.get("victimId", "unknown"),
                  weapon=event.get("weapon", "unknown"),
                  round_number=current_round_number,
                  ability_cast=ability_cast,
              )
              current_round_kills.append(kill)

          # ------------------------------------------------------------------
          # round-ended: seal the round and append to the current game
          # ------------------------------------------------------------------
          elif event_type == "round-ended":
              if current_round_number is None:
                  continue
              parsed_round = ParsedRound(
                  round_number=current_round_number,
                  kills=list(current_round_kills),
                  winner_team_id=event.get("winnerTeamId"),
              )
              completed_rounds.append(parsed_round)
              current_round_number = None
              current_round_kills  = []

          # ------------------------------------------------------------------
          # game-ended: seal the game and append to the series
          # ------------------------------------------------------------------
          elif event_type == "game-ended":
              if current_game_id is None:
                  continue
              parsed_game = ParsedGame(
                  game_id=current_game_id,
                  map_id=current_map_id,
                  rounds=list(completed_rounds),
              )
              completed_games.append(parsed_game)
              current_game_id    = None
              current_map_id     = None
              completed_rounds   = []

          # ------------------------------------------------------------------
          # series-ended: nothing to accumulate; exit handled after the loop
          # ------------------------------------------------------------------
          elif event_type == "series-ended":
              pass

          # ------------------------------------------------------------------
          # Unknown event types are silently ignored — GRID schema evolves.
          # ------------------------------------------------------------------

      return ParsedSeries(
          series_id=series_id or "",
          games=completed_games,
      )
  ```
